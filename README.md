# JS-Cumprimento
Um código simples que cumprimenta alguém com uma função onde há uma váriável com nome, fiquem livres para editar e colocar o nome que quiserem!
# Como usar?
É necessário ter a extensão Code Runner no VS Code para usar sem navegador. Depois, clique no botão de executar e você verá o código rodar!
# Como personalizar?
A variável para editar o nome está na linha da função dentra do parenteses. manter com as aspas, assim não dá problema no projeto!
